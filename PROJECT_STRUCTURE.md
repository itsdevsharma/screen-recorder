## Key Directories Explained

### src/app/
Next.js App Router directory structure
- Houses all pages and layouts
- API routes for backend

### src/api/videos/
All video-related API endpoints
- GET: Fetch videos
- POST: Upload and process videos
- DELETE: Remove videos
- Analytics endpoints

### src/components/
React components
- ScreenRecorder: Main component with all functionality

### src/lib/
Utility functions and helpers
- Database connection
- File upload handling
- Video processing

### src/models/
Database models (Mongoose schemas)
- Video schema with all fields

### src/styles/
CSS styling
- Global and component styles
- Preserved from original project

### public/
Static assets
- Uploads directory for temporary files

### (Root)
Configuration and documentation
- Next.js, TypeScript, ESLint config
- README and guides
- package.json with all dependencies
